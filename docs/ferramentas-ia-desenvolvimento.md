# Lista de Repositórios de Ferramentas para IA e Desenvolvimento

Esta lista compila ferramentas open-source e frameworks projetados para aprimorar o fluxo de trabalho com agentes de IA (como Claude), focando em memória, planejamento, UI/UX e automação.

## 1. Frameworks e Metodologias

- **[Superpoderes](https://github.com/obra/superpowers)**: Framework de skills e metodologia de desenvolvimento que força o agente a pensar e planejar antes de codificar.
- **[Habilidades do Karpathy](https://github.com/multica-ai/karpathy-skills)**: Diretrizes baseadas em Andrej Karpathy para evitar suposições erradas e simplificar soluções de código.
- **[Ralph Loop](https://github.com/snarktank/ralph)**: Loop autônomo que continua construindo iterativamente até completar a tarefa.

## 2. Memória e Contexto

- **[claude-mem](https://github.com/thedotmack/claude-mem)**: Sistema de memória persistente para permitir que o Claude retome sessões de onde parou.
- **[Context7](https://github.com/upstash/context7)**: Ferramenta para puxar documentação atualizada e específica por versão, evitando alucinações de API.

## 3. UI/UX e Visualização

- **[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)**: Skill com 161 paletas e 57 combinações de fontes para padronizar design em apps gerados por IA.
- **[Excalidraw Diagram Skill](https://github.com/excalidraw-diagram-skill)**: Transforma descrições textuais em diagramas de arquitetura limpos e auto-corrigidos.
- **[HeyGen HyperFrames](https://github.com/heygen-com/hyperframes)**: Renderiza vídeos MP4 reais a partir de HTML, útil para criar demos e reels via prompt.

## 4. Automação e Testes

- **[Agent Browser](https://github.com/vercel-labs/agent-browser)**: CLI de automação de navegador nativo em Rust que permite ao agente navegar e testar sites ao vivo.
